Vier Schritte bis zur Kopplung. Danach zeigt dir diese Seite live, was die Box meldet, bis die erste Figur spielt.

  1. 1. Hardware bereitlegen

    Raspberry Pi 4, NFC-Leser PN532, Verstärker MAX98357A mit Lautsprecher, vier Taster, microSD-Karte (32 GB) und Netzteil (5,1 V / 3 A).

    Einkaufsliste und Verdrahtung

  2. 2. Image auf die SD-Karte

    Lade das neueste Image herunter (myboxi-….img.xz). Im Raspberry Pi Imager: Gerät „Raspberry Pi 4“, „Eigenes Image verwenden“, die Datei und die SD-Karte wählen, schreiben.

    Image herunterladen

  3. 3. Einschalten und WLAN einrichten

    1. SD-Karte einlegen, Netzteil anstecken. Der erste Start dauert etwa zwei Minuten.
    2. Die Box sagt „Einrichtung …“. Verbinde dein Handy mit dem WLAN Myboxi-NNNN. Die Einrichtungsseite öffnet sich von selbst, sonst http://10.42.0.1/ aufrufen.
    3. Heim-WLAN wählen und das Passwort eingeben. {% if custom_server %}Als Server {{ server_url }} eintragen.{% else %}Den Server nicht ändern.{% endif %}

    Kein WLAN „Myboxi-…“ zu sehen? „Lauter“ und „Leiser“ gleichzeitig 5 Sekunden halten, dann startet die Einrichtung neu.

  4. 4. Code eingeben

    Sobald die Box online ist, sagt sie einen sechsstelligen Code an. „Play/Pause“ wiederholt ihn.
