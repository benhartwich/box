  1. 1

    Spotify-App anlegen

    1. Das Spotify-Entwicklerportal öffnen und mit dem Spotify-Konto anmelden, das Spotify Premium hat. Beim ersten Mal die Bedingungen bestätigen.
    2. „Create app“ wählen. Name zum Beispiel „Myboxi“, Beschreibung beliebig.
    3. Bei „Redirect URIs“ genau diese Adresse eintragen und „Add“ tippen:
    4. Bei „Which API/SDKs are you planning to use?“ „Web API“ ankreuzen, den Bedingungen zustimmen und speichern.
  2. 2

    Client-ID eintragen

    In der neuen App unter „Settings“ bei „Basic Information“ die „Client ID“ kopieren. Das „Client secret“ braucht Myboxi nicht.

  3. 3

    Mit Spotify verbinden

    Spotify fragt, ob Myboxi eure Playlists und gespeicherten Alben lesen darf. Mehr kann Myboxi damit nicht: nichts abspielen, nichts ändern.

    Meldet Spotify, das Konto sei für die App nicht freigeschaltet: in der App unter „User Management“ Name und E-Mail des Spotify-Kontos eintragen. Spotify erlaubt dort höchstens 5 Konten.

Den Spotify-Schlüssel für die Box gibt es im selben Portal unter „Spotify Soloist API Key“. Er wird nur im Einrichtungsmodus der Box eingetragen, nie hier.
