Spotify einrichten

Mit Spotify Premium spielt eine Figur ein Album oder eine Playlist. Ihr richtet das einmal ein, in drei Teilen. Spotify erlaubt dabei nur private, nicht-kommerzielle Nutzung.

  1. 1

    Auf der Box

    1. Im Spotify-Entwicklerportal mit dem Premium-Konto anmelden, „Spotify Soloist API Key“ öffnen und einen Schlüssel erzeugen.
    2. Den Einrichtungsmodus der Box starten: lauter und leiser 5 Sekunden halten. Auf der Einrichtungsseite unter „Spotify (optional)“ den Schlüssel einfügen. Hier in Myboxi wird er nie eingetragen.
    3. Auf der Box-Seite unter „Quellen“ Spotify einschalten. Die Box lädt Spotify dann selbst herunter.
    4. Einmal anmelden: Handy im selben WLAN, in der Spotify-App etwas abspielen, unten auf das Geräte-Symbol tippen und die Box („Myboxi“ und ihre vier Ziffern) wählen.

    1. Im Spotify-Entwicklerportal „Create app“ wählen. Name zum Beispiel „Myboxi“, Beschreibung beliebig.
